# Chess-Eternal-Blitz-
Four player Chess Variant, with free for all (1v1v1v1) and Teams (2v2) free for all is a digital custom rendition of the middle aged Indian Chess Variant "Chaturaji" and the Teams version is a digital basic rendition of the Victorian era occult chess game "Enochian Chess". This current Repo has the VS CPU build. Online with casual and ranked soon!!
